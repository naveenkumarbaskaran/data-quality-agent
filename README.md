# Data Quality Agent

An AI-powered data quality tool that combines local statistical profiling with
Claude (claude-sonnet-4-6) to produce detailed, actionable data quality reports.

## Features

- **Automated profiling** — per-column statistics (mean, std, null rates, quantiles,
  skewness, kurtosis, top values, string-length distribution)
- **Anomaly detection** — IQR-based outlier detection for numeric columns;
  rare-frequency detection for categorical columns
- **Schema drift detection** — compare a baseline profile JSON against the current
  dataset to flag added/removed columns and type changes
- **AI-generated reports** — Claude synthesises all findings into a structured
  Markdown report with an executive summary, quality score, and prioritised
  recommendations
- **CLI** — `dq-agent profile`, `dq-agent compare`, `dq-agent quick-profile`
- **Python API** — embed `DQAgent` and `DataProfiler` in your own pipelines

## Quick Start

### CLI

```bash
# Set your Anthropic API key
export ANTHROPIC_API_KEY="sk-ant-..."

# Generate a full AI-powered report
dq-agent profile data.csv --output report.md

# Generate a report and save the profile for later comparison
dq-agent profile data.csv --output report.md --save-profile baseline.json

# Compare the current dataset against a saved baseline
dq-agent compare --baseline baseline.json --current new_data.csv

# Quick local profiling without calling Claude
dq-agent quick-profile data.csv --output profile.json
```

### Python API

```python
from dq_agent import DQAgent, DataProfiler

# --- Local profiling (no API key needed) ---
profiler = DataProfiler()
profile = profiler.profile("data.csv")
print(profile["shape"])            # [5000, 12]
print(profile["stats"]["price"])   # {'mean': 42.3, 'null_rate': 0.02, ...}

anomalies = profiler.detect_anomalies("data.csv", "price")
print(anomalies["summary"])        # '7 outlier(s) found in \'price\' (bounds: ...)'

# --- AI-powered report ---
agent = DQAgent()   # reads ANTHROPIC_API_KEY from environment
report = agent.analyse("data.csv")
print(report)       # full Markdown report

# --- Save a profile and use it as a baseline next time ---
agent.save_profile("data.csv", "baseline.json")

import json
baseline = json.loads(open("baseline.json").read())
report = agent.analyse("new_data.csv", baseline_profile=baseline)
```

## CLI Reference

### `dq-agent profile`

Run a full AI-powered data quality analysis.

```
Usage: dq-agent profile [OPTIONS] PATH

Arguments:
  PATH  CSV or Parquet file to analyse.

Options:
  -o, --output PATH        Output path for the Markdown report.  [default: report.md]
  -b, --baseline PATH      Baseline JSON profile for schema-drift detection.
  --save-profile PATH      Save the computed profile as JSON.
  --model TEXT             Claude model to use.  [default: claude-sonnet-4-6]
  --api-key TEXT           Anthropic API key (or set ANTHROPIC_API_KEY).
  --help                   Show this message and exit.
```

### `dq-agent compare`

Compare a baseline profile with a current dataset for schema drift.

```
Usage: dq-agent compare [OPTIONS]

Options:
  -b, --baseline PATH      Baseline JSON profile.  [required]
  -c, --current PATH       Current data file or profile JSON.  [required]
  --json                   Output results as JSON.
  --help                   Show this message and exit.
```

### `dq-agent quick-profile`

Compute and display statistics without invoking Claude.

```
Usage: dq-agent quick-profile [OPTIONS] PATH

Arguments:
  PATH  CSV or Parquet file to profile.

Options:
  -o, --output PATH        Save profile JSON to this path.
  --help                   Show this message and exit.
```

## Report Structure

The AI report generated by `dq-agent profile` includes:

1. **Executive Summary** — top-level quality verdict and critical issues
2. **Dataset Overview** — file path, shape, column count, dtypes
3. **Per-Column Statistics** — null rates, distributions, top values, outlier counts
4. **Anomaly Findings** — detailed outlier/rare-value analysis per flagged column
5. **Schema Drift Analysis** — added/removed columns, type changes (when baseline provided)
6. **Data Quality Score** — 0-100 score with rationale
7. **Recommendations** — prioritised action items

## How It Works

```
User request
     │
     ▼
  DQAgent.analyse()
     │
     ▼
  Claude (claude-sonnet-4-6)
  ├── calls read_csv        → DataProfiler._load() + preview
  ├── calls profile_dataframe → DataProfiler.profile()
  ├── calls detect_anomalies → DataProfiler.detect_anomalies()
  └── synthesises Markdown report
```

`DQAgent` runs an agentic loop: it passes tool definitions to the Anthropic API,
executes the tool calls locally via `DataProfiler`, feeds the results back, and
continues until Claude produces a final `end_turn` response.
